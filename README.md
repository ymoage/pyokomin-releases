# Pyokomin

YouTube ライブのチャットを、レーンに分けて読むための Windows のアプリです。いまは β版です。

Pyokomin は無料です。β版のあとの正式版になっても、すべての機能を無料で使えます。

ホームページ: https://pyokomin.com/

## ダウンロード

[最新のリリース](https://github.com/ymoage/pyokomin-releases/releases/latest) の「Assets」から、どちらか一方をダウンロードしてください。

- `Pyokomin-Setup-（版）.exe` … インストーラー（おすすめ）
- `Pyokomin-（版）-win-x64.zip` … インストーラーを使いたくない人向け

入れかた・zip の使いかた・Windows の警告が出たときのことは、[はじめかた](https://pyokomin.com/guide/install.html) をご覧ください。

ダウンロード・使うことで、[利用規約](https://pyokomin.com/terms.html) に同意したものとみなします。情報の扱いは [プライバシーポリシー](https://pyokomin.com/privacy.html) に書いています。

## 動作環境

- Windows 10・11（64 ビット）
- Microsoft Edge WebView2 ランタイム（Windows 11 には最初から入っています）

## 本物か確かめるには

- リリースの `SHA256SUMS.txt` に、ファイルごとの SHA-256 の値があります
- アプリとインストーラーには、開発者が自分で作った証明書で署名しています。署名者は「Pyokomin (ymoage)」、証明書の指紋は `B85AEAC18BD50A84506DD4593B37E08453EDF03B` です。証明書を Windows に入れる必要はありません

## 不具合を見つけたら

アプリの上のバーにある虫のボタン（または Ctrl+Shift+B）から送ってください。メールでのお問い合わせは、ホームページのお問い合わせ先へ。
